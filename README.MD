# Desafio Target Sistemas

Repositório com a implementação de três desafios técnicos propostos pela **Target Sistemas**, desenvolvidos em **C#**.

Os desafios abordam diferentes situações práticas, envolvendo cálculo de comissões, controle de estoque e cálculo de juros.

## 🧩 Desafios

### 1. 💰 Comissões

Desafio voltado para o cálculo de **comissões sobre vendas**, utilizando valores de vendas e regras de cálculo para determinar a comissão correspondente.

**Conceitos praticados:**

- Variáveis e tipos numéricos
- Operações matemáticas
- Estruturas condicionais
- Entrada e saída de dados
- Formatação de valores

---

### 2. 📦 Estoque

Desafio relacionado ao **controle e gerenciamento de estoque**, trabalhando com produtos, quantidades e operações de movimentação de estoque.

**Conceitos praticados:**

- Classes e objetos
- Manipulação de dados
- Estruturas condicionais
- Operações com quantidades e valores
- Organização de código

---

### 3. 📈 Cálculo de Juros

Desafio voltado para o **cálculo de juros**, utilizando valores financeiros e períodos para determinar os resultados das operações.

**Conceitos praticados:**

- Operações matemáticas
- Tipos numéricos
- Cálculos financeiros
- Entrada de dados
- Formatação de resultados

## 🛠️ Tecnologias

- **C#**
- **.NET**

## 🚀 Como executar

**Se estiver em ambiente windows, pode simplesmente navegar até a pasta bin/Debug/net10.0 e abrir o executavel, caso não seja possivel, segue o passo a passo:**


### Pré-requisitos

Para executar os desafios, é necessário ter o **.NET SDK** instalado.

Clone o repositório:

```bash
git clone https://github.com/jdelta22/DesafioTargetSistemas.git
```

Entre no diretório do projeto:

```bash
cd DesafioTargetSistemas
```

Cada desafio possui seu próprio diretório:

```text
DesafioTargetSistemas/
├── Desafio1/
├── Desafio2/
└── Desafio3/
```

Para executar um desafio, entre no diretório correspondente e utilize:


```bash
dotnet run
```

Por exemplo:

```bash
cd Desafio1
dotnet run
```

## 🎯 Objetivo

O objetivo deste projeto é demonstrar a aplicação de conhecimentos fundamentais de **C# e lógica de programação** na resolução de problemas práticos.

Os desafios também fazem parte do processo de avaliação técnica da **Target Sistemas**.
